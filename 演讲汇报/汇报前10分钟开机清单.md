### 点 5 的讲解三亮点（背下来）

1. **bnb NF4 4bit 量化** —— 8G 显存能跑 4B 模型的秘诀

3. **手拼 im_start 对话模板** —— 和训练时格式严格一致，否则效果全废

## 🚑 救命锦囊

**A. start.sh 卡住 / 没出完成行**
```bash
# 看 Ollama 有没有在
curl -s http://localhost:11434/api/tags | head -c 100
# 看 API 日志尾部定位是谁没起
ss -tlnp | grep -E ':(8000|8002|11434)'
```
缺谁单独起：Ollama 用 `nohup ollama serve &`，API/ASR 重跑 `bash start.sh` 即可（幂等）。

**B. VS Code 里 ▶ 报 `No module named torch`**
`Ctrl+Shift+P` → `Python: Select Interpreter` → 选 `shixun-venv`。
实在不行用终端那条命令（百分百能跑）：
```bash
cd ~/medical-ft && ~/shixun-venv/bin/python compare_4way.py
```

**C. 跑代码时报显存不足 / 特别慢**
说明 Ollama 或别人在用医小咪抢显存：
```bash
# 让 Ollama 立刻卸载模型、释放显存
curl -s http://localhost:11434/api/generate -d '{"model":"qwen3.5:4b-med3","keep_alive":0}' >/dev/null
nvidia-smi --query-gpu=memory.used --format=csv,noheader   # 应回落
```
另外：**演示代码时别让同学/老师同时点网页提问**。

**D. 网页打不开 / 公网地址 404**
- 先确认 `curl http://localhost:8000/health` 是 ok
- 局域网转发失效（WSL 重启后 IP 变了）→ 呼叫咪咪修 portproxy
- 公网隧道断了 → 重跑 `bash start.sh`（第 5 段会自动拉起隧道）

**E. 彻底翻车（进程全乱）**
重启 WSL 后跑一键恢复：`bash /mnt/c/Users/wpc15/Desktop/restart_yixiaomiao.sh`
再 `bash start.sh` 补齐即可。
