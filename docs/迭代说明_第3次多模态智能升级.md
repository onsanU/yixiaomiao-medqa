## 一、本次迭代目标

在 v1.0（RAG 文字问答 + 多用户 + 防幻觉，8 环节验收通过）基础上，将医小喵从"纯文字问答助手"升级为**"会看、会听、会管理"的多模态健康助手**：

1. **能看图**：用户上传/粘贴检查报告、化验单、症状照片，自动解读（OCR + 视觉双通道分流），报告指标异常自动标红并出对比图
2. **能听**：浏览器录音即可提问（SenseVoice 语音识别），解放打字
3. **能管理**：问完病情一键生成可执行的"护理行动计划卡"（吃什么注意什么、什么信号要就医、什么节奏复查）
4. **性能与环境**：Ollama 升级 + 主脑模型换代，让多模态能力在 8G 显存笔记本上流畅运行；同步完成泰迪多模态实训 QwenVL 视觉块（任务 7-9）与 SenseVoice 语音块（任务 10-14）的真实落地

## 二、完成内容

### 1. 📷 AI 看图解读（2026-09-02，`app/vision.py` + `POST /vision/analyze`）
- 支持聊天界面**上传图片 / Ctrl+V 粘贴截图**，自动分流：
  - **OCR 文字通道**：RapidOCR 提取文字 ≥30 字（报告/化验单/说明书类）→ 交给主脑 `qwen3.5:4b` 文字解读（文字推理不错位，最准）
  - **视觉通道**：OCR 文字太少（症状照片/无字图）→ `qwen2.5vl:3b` 视觉模型直接看图（100% GPU，单次约 10s，`keep_alive=0` 用完即卸）
- **报告解读图表化**：解读同时提取结构化指标（metrics），前端用 ECharts 渲染指标对比图，**超标项自动标红**，一眼看清问题项
- 解读结果按用户写入问答历史（可回看/继续追问）

### 2. 📋 护理行动计划卡（2026-09-02，`app/plan.py` + `POST /plan`）
- 用户点"📋 生成护理计划"按钮 → 按原问题检索知识库 → `qwen3.5:4b`（think=False）生成结构化计划 JSON：`{condition, summary, level, items(3-7条可执行行动), dangers(危险信号), timeline(复查节奏)}`
- 安全设计：内容必须基于知识库检索结果（沿用 RAG 防幻觉体系）；**不涉及具体药物剂量**（只写"遵医嘱用药"）；资料没提危险信号时给通用就医提醒
- 计划同步存历史，可随时回看打卡

### 3. 🎤 语音输入（2026-09-03，`app/asr_server.py` 独立微服务 + `POST /asr` 转发）
- SenseVoiceSmall ASR 独立微服务（127.0.0.1:8002，独立 venv `~/sensevoice-venv`，模型常驻首次加载约 8s 之后秒回）
- 前端录音（webm）→ base64 → `/asr` 转发 → 中文识别文本（SenseVoice 自带标点 + 情感标记）→ 填入输入框提问
- 音频上限 20MB，模型跑 CPU 不占显卡

### 4. ⚡ Ollama 升级 0.17.5 → 0.33.2
- 旧版 0.17.5 视觉模型**不上 GPU**、推理慢；升级后视觉模型跑满 GPU（推理快约 9 倍）、问答整体提速约 7 倍
- 系统内存占用从约 8.5G 降至约 1.4G（配合 `keep_alive=0` 用完即卸）

### 5. 🔄 模型换代（主脑升级）
- 主脑：Qwen2.5-7B → **qwen3.5:4b**（更快更省内存，RAG 问答/OCR 文字解读/护理计划共用）
- 视觉：新增 **qwen2.5vl:3b**（中文看图，100% GPU）
- 向量：qwen3-embedding:0.6b（ChromaDB 检索）
- 配套：WSL 内存提升至 12G（`.wslconfig`，宿主 15.2G 够用），支撑视觉模型 8.4G 内存需求

### 6. 🖥️ 前端与工程配套
- 深色医疗科技风界面新增：图片上传/粘贴入口、录音按钮、护理计划按钮、ECharts 报告图表渲染
- `start.sh` 升级为**一键三件套**：Ollama → ASR(8002) → API(8000)，自动就绪检查
- 项目目录迁移至英文名 `yixiaomiao-medqa`（规避 WSL 中文路径 9p bug），Git 历史完整保留，start.sh/asr_server/README/docs 路径同步更新

## 四、遇到的问题与解决

| 问题 | 解决方案 |
|------|---------|
| 小视觉模型（moondream/granite）看图只会英文回答，中文体验差 | 换 qwen2.5vl:3b（中文最佳）——但其需 8.4G 内存 > WSL 默认 7.4G，故写 `.wslconfig` 提内存到 12G + swap 4G（重启生效） |
| Ollama 0.17.5 太老：视觉模型不上 GPU、推理慢、吃系统内存 | 升级 0.33.2（新版解压 + symlink，旧版备份 .bak-0.17.5） |
| 视觉/大模型常驻内存占用高 | Ollama API 调用加 `keep_alive=0`，用完即卸 |
| qwen3 think 模式超长思考烧光预算（OCR 通道踩坑） | 护理计划等固定任务显式 `think=False` |
| OCR 首次初始化慢（4-8s） | 懒加载单例：首次调用才 import + 初始化 |
| 中文目录名在 WSL 出现 9p 访问 bug | 项目迁移英文目录 `yixiaomiao-medqa`，5 处路径引用 + 技能 + 记忆同步更新 |
| 前端录音格式/大小不可控 | webm + base64 上传，服务端 20MB 上限校验 |
