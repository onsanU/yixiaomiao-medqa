## 一、本次迭代目标

在正式开发前，先验证项目核心技术链路（本地大模型 + RAG 检索增强生成）是否可行，降低后期返工风险。对应课程8环节中的【③智能问答核心功能实现】【④医疗知识库搭建与维护】的技术预研。

## 二、完成内容

1. **本地大模型部署验证**：Ollama + Qwen3.5 4B，GPU（RTX 5070 / CUDA）推理正常
2. **向量检索验证**：qwen3-embedding:0.6b（639MB 中文向量模型）+ ChromaDB 向量库，8 条医疗知识入库，提问检索命中准确
3. **RAG 全链路合体**：提问 → 向量检索 → 拼上下文 → Qwen 生成回答，4 组测试全部通过
4. **防幻觉测试通过**：提问知识库外内容（"火星上能种土豆吗"），模型如实回答"资料库中暂无相关内容"，未胡编乱造

## 四、遇到的问题与解决

| 问题 | 解决方案 |
|------|---------|
| Ollama 关机后需手动启动，步骤繁琐 | 编写一键启动脚本 start_ollama.sh |
| bge-m3 模型过大（1.2GB，下载约20分钟） | 改用 qwen3-embedding:0.6b（639MB，中文效果好） |
| bge-small-zh / bge-large-zh 在 Ollama 库不存在 | 改用 Qwen 家族 embedding 模型 |
| langchain 1.x 需额外安装 Ollama/Chroma 接口包 | 安装 langchain-ollama / langchain-chroma / langchain-text-splitters |
