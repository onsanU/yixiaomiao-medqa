## 一、本次迭代目标

主人计划将医小喵放到公网使用。此前系统"输入昵称即可用"（无账号体系），管理后台 `/admin` 也完全裸奔——医疗问答记录属隐私数据，公网暴露不可接受。本次迭代：

1. **账号密码登录**：注册/登录后才能使用聊天，历史归属账号（防伪造他人身份）
2. **安全加固**：密码加密存储、登录防爆破限流、防用户名枚举、会话令牌可吊销
3. **后台保护**：`/admin` 全部页面与 API 仅管理员可访问（登录页 + 三级权限）
4. **账号管理**：管理后台可查看注册账号、重置密码、切换角色（主人怎么管用户）
5. **测试适配**：pytest 全面适配登录制并新增认证用例

## 二、完成内容

### 1. 🔐 认证核心（`app/auth.py`）
- **密码哈希 PBKDF2-HMAC-SHA256**（标准库 hashlib，60 万次迭代 + 每用户随机盐，格式 `pbkdf2_sha256$600000$salt$hash`）——绝不存明文、不可逆
- **登录令牌**：`secrets.token_urlsafe(32)` 明文仅登录响应下发一次，数据库只存 sha256 哈希（库泄露不可直接用）；7 天有效期
- **鉴权依赖**：`current_user`（聊天接口，X-Auth-Token → 用户）+ `current_admin`（管理 API，组合校验角色）

### 2. 🌐 认证 API（`app/auth_api.py`，前缀 /auth）
| 接口 | 说明 |
|------|------|
| POST /auth/register | 注册（首个账号自动 role=admin）+ 自动登录返回 token |
| POST /auth/login | 登录（恒时比较防枚举 + 5次/分钟/IP 限流）→ {token, username, role} |
| POST /auth/logout | 登出（吊销会话，可立即失效） |
| GET /auth/me | 校验 token 返回当前账号（前端启动自动登录用） |
| POST /auth/reset | [管理员] 重置任意用户密码 + 吊销其全部会话（忘记密码唯一途径） |
| POST /auth/role | [管理员] 切换角色 admin/user（防自降级；降级即吊销会话） |

- 安全细节：用户不存在也执行一次完整 PBKDF2（防时序枚举）；注册/登录共享限流（防灌号+爆破）；X-Forwarded-For 取真实 IP（公网反代场景）

### 3. 🗄️ 数据库（db.py 扩展，SQLite/MySQL 双后端同步建表）
- `users` 表：username(唯一)/password_hash/role(admin|user)/created_at
- `sessions` 表：token_hash(唯一)/username/expires_at（可吊销、可查归属）
- 通用修复：fetch_all 将所有 datetime 列统一转字符串（MySQL DATETIME 对象 vs SQLite 字符串，双后端一致）

### 4. 🔌 主业务接口鉴权（main.py）
- /chat /chat/stream /vision/analyze /asr /plan /history(DELETE) 全部要求登录，**user 不再由前端传，改从 token 取**（杜绝伪造他人身份提问）
- /topics /tip 公开（无害数据）；猫咖 /cat/* /haiku /pet /music 保持公开（MeowCafe 是 file:// 直连的独立项目，不能强制登录）

### 5. 🎨 聊天前端登录屏（app/static/index.html，深色风一致）
- 登录/注册卡片（用户名 2-20 位中文/字母/数字/下划线、密码 ≥6 位、错误提示、回车提交）
- 登录后显示「👤 账号名」（管理员带 ⭐），点击可退出
- **全局 fetch 注入 X-Auth-Token + 401 自动踢回登录屏**（一处封装，所有请求生效）
- 启动时 checkAuth：有 token 自动进聊天 / 无则盖登录屏
- 历史跟随账号：注册同名自动接管旧昵称记录（如注册"主人"即看到原来"主人"的 12+ 条历史）

### 6. 🛡️ 管理后台保护（AdminLTE 5 页）
- 新增 `/admin/login.html`：管理员登录卡（非 admin 提示无权；已登录管理员自动进看板）
- 4 个既有页面 + 新增账号管理页全部加 `guardAdmin()` 守卫（无 token/非 admin → login.html），api() 自动带 token，401/403 跳登录
- 新增 **`/admin/accounts.html` 账号管理页**：账号列表（用户名/角色徽标/注册时间/问答数）+ 重置密码 + 设为管理员/降级（自己不可降，前端无按钮 + 后端 400 双保险）+ 安全说明

## 四、遇到的问题与解决

| 问题 | 解决方案 |
|------|---------|
| 新版 FastAPI 路由树静态检查困难 | 直接起服务 curl 实测（auth 6 接口逐个验证） |
| MySQL DATETIME 对象再坑一次（sessions.expires_at 比较崩） | fetch_all 通用化：所有 datetime 列统一 strftime 转字符串（不再只转 created_at） |
| 测试全部 401（无 token） | tests 适配：固定测试账号 pytestA/B 自动注册/登录，autouse fixture 每测后清理其聊天记录（账号保留避免 users 无限膨胀） |
| /admin 4 页逐个加守卫重复代码 | 统一 guardAdmin() 代码块 + 各页 api() 注入 token（KISS：每页独立小段，避免过度抽象） |
| 流式响应闭包引用依赖对象（潜在竞态） | username 提前绑定局部变量再进 generator |
| localStorage 被浏览器安全策略拦截无法脚本验证 | 改用 DOM 状态断言（authScreen class / userChip 文本） |
