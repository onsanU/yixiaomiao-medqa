# 部署说明 · 医小喵

## 一、部署架构

```
浏览器(用户) → FastAPI(localhost:8000) → RAG(app/rag.py) → Ollama(localhost:11434)
                                                    ↓
                                              Qwen3.5 4B + qwen3-embedding
```

- 全部组件运行在本机，**断网可用**（模型与知识库均在本地）
- 局域网内其他设备可通过 `http://<本机IP>:8000` 访问（服务已绑定 0.0.0.0）

## 二、一键部署

```bash
bash start.sh
```

脚本自动完成：检查/启动 Ollama → 检查模型 → 启动 API 服务 → 输出访问地址

## 三、手动部署

1. 启动 Ollama：`ollama serve`
2. 启动 API：`source ~/medqa-venv/bin/activate && uvicorn app.main:app --host 0.0.0.0 --port 8000`
3. 浏览器访问：http://localhost:8000

## 四、知识库更新（扩充内容）

1. 新增资料：往 `data/raw/web/` 或 `data/raw/manual/` 放入 md 文件
2. 重建知识库：`python build_kb.py`
3. 重启 API 服务即可生效

## 五、接口一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | / | 聊天页面 |
| POST | /chat | 问答（JSON: question, user, history?） |
| POST | /chat/stream | 流式问答（NDJSON） |
| GET | /history?user=xxx | 用户问答历史+个性化推荐 |
| DELETE | /history?user=xxx | 清空用户历史 |
| GET | /topics | 27个知识主题列表 |
| GET | /tip | 今日健康贴士 |
| GET | /health | 健康检查 |

## 六、常见问题

| 问题 | 解决 |
|------|------|
| 启动后页面打不开 | 检查 8000 端口是否被占用；看 /tmp/yixiaomiao_api.log |
| 问答很慢 | 确认 Ollama 用 GPU 推理（ollama ps 看进程） |
| 局域网别人访问不了 | 放行 Windows 防火墙 8000 端口 |
| 历史被清空 | 用户各自用昵称登录，历史按昵称隔离 |
